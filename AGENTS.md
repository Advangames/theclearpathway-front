# Frontend - Next.js Directory Structure

This directory contains the mvp frontend application built with Next.js.

## Directory Structure

- `app/` - Next.js app directory with pages, layouts and api routes
- `public/` - Static assets like images and fonts
- `src/` - Source code and assets
- `src/styles/` - Global styles and CSS files
- `src/components/` - Reusable React components
- `src/hooks/` - Custom React hooks
- `src/utils/` - Utility functions for other functions / components
- `src/adapters/services/` - ts functions that do fetch requests to the backend, using src/adapters/dto in case is needed
- `src/context/` - React context providers
- `src/providers/` - Component providers
- `app/(pages)/` - Page components
- `next.config.js` - Next.js configuration
- `package.json` - Node.js dependencies and scripts
- `tsconfig.json` - TypeScript configuration
- `README.md` - Project documentation
